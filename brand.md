# Brand Design System — SnowRaven

## Visual Identity

**Primary color:** #2D8653 — Irish clover green
**Feeling:** Simple, straightforward, and intuitive — calm and purposeful, no clutter
**Typography:** Clean and modern — sans-serif, neutral
**Reference:** dtgibson.com

## Design Token Values

| Token | Value | Usage |
|---|---|---|
| --primary | #2D8653 | Buttons, links, key actions |
| --primary-foreground | #FFFFFF | Text on primary color |
| --background | #FFFFFF | Page background |
| --foreground | #0F1117 | Primary text |
| --card | #FFFFFF | Card backgrounds |
| --card-foreground | #0F1117 | Text on cards |
| --muted | #F4F4F5 | Muted surface backgrounds |
| --muted-foreground | #71717A | Secondary / placeholder text |
| --accent | #E8F5EE | Hover states, light highlights |
| --accent-foreground | #1A5C38 | Text on accent |
| --secondary | #F0FAF4 | Secondary surfaces |
| --secondary-foreground | #2D8653 | Text on secondary |
| --destructive | #EF4444 | Error / destructive actions |
| --destructive-foreground | #FFFFFF | Text on destructive |
| --border | #E4E4E7 | Borders |
| --input | #E4E4E7 | Input borders |
| --ring | #2D8653 | Focus rings |
| --radius | 0.5rem | Border radius |

## Typography

**Font pairing:** Inter, system-ui, sans-serif (single family — clean and neutral)
**Heading weight:** 600
**Body size:** 16px / 1.5 line-height

## Applied To
`frontend/src/globals.css`

## Notes
The green should feel grounded and natural, not corporate. The overall aesthetic is quiet utility — the kind of tool that gets out of the user's way. Reference site (dtgibson.com) reinforces a clean, content-first approach with restrained use of color.
