Start the dev server myself and provide a clickable link to the running app. Do not ask the user to open a terminal or run the start command — do it directly.

**Why:** User preference — confirmed when I asked them to run `npm run dev` instead of doing it myself.

**How to apply:** At every Engineer gate where the user needs to verify a feature, start the dev server (or confirm it's already running), then provide the direct URL as a clickable link.
