Accessibility — Design Specification

Overview
What this spec covers
Most accessibility improvements are invisible — ARIA attributes, keyboard handlers, focus traps. This document covers the changes that are visible, the patterns that apply across components, and the exact ARIA markup the Engineer will implement.
  • ✓1 contrast fix — tier-1 breeding code badge text (visible color change)
  • ✓Focus ring styling — verified visible on all interactive elements in both themes
  • ✓Touch target sizing — 44×44px minimum on all interactive controls
  • ✓Visually-hidden labels — tier names and recency labels added for screen readers
  • ✓ARIA patterns — tab bar, filter pills, toggle switches, combobox, live regions across all tabs
  • ✓Semantic HTML — form labels, heading hierarchy, table roles across all tabs
Visible Changes
1. Tier-1 badge contrast fix
The only color change in this pass. Tier-1 ("Possible") breeding code badges use a light purple background. White text on that background fails WCAG AA (2.7:1). Switching to the dark purple text (#3B0764) brings contrast to 6.8:1 — well above the 4.5:1 threshold.

Non-Color Alternatives
5. Visually-hidden labels
The .sr-only utility class hides text visually while keeping it accessible to screen readers. Used for breeding tier names and map recency labels.
Breeding code badge — screen reader reads
Visually: purple circle with "S". VoiceOver: "S, Possible"
<div class="tier-badge tier-1"> S <span class="sr-only"> , Possible </span> </div>
Map recency dot — screen reader reads
Visually: green dot. VoiceOver: "American Robin — Recent (≤7 days)"
American Robin — Brown's Island
sr-only: "Recent (≤7 days)"
Yellow Warbler — River Trail
sr-only: "Seen 8–14 days ago"
Indigo Bunting — Oak Meadow
sr-only: "Seen 15–30 days ago"
.sr-only CSS utility (globals.css)
Added once; used throughout. Visually hidden but fully accessible to screen readers.
/* Add to globals.css if not already present */ .sr-only { position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0, 0, 0, 0); white-space: nowrap; border-width: 0; }
