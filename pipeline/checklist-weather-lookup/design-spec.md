# Design Spec — Checklist Weather Lookup

## Visual Direction
Clean, minimal, and purposeful — the app gets out of the way and lets the output speak. Irish clover green (#2D8653) is used as a single accent color on the primary action only. The overall feeling is calm utility: a focused tool that does one thing well.

## Screens / Views

### Main Screen (single view)
A centered card (max-width 540px) on a light gray page background (#f9fafb). The card has a white background, 1px border, 12px border radius, and a subtle two-layer box shadow.

**Header (above card):**
- Bird icon (Lucide `Bird`) in primary green, 30px
- App name "SnowRaven" in 26px / weight 700, with "Raven" in primary green
- Tagline "Weather for your eBird checklists" in 14px muted gray below

**Input area (inside card):**
- Field label: "eBird checklist ID or URL" — 14px, weight 500
- Text input: 44px tall, 1.5px border, 8px radius. Focus state: primary green border + 3px green shadow ring
- Placeholder: "S12345678 or https://ebird.org/checklist/S12345678"
- Submit button: 44px tall, primary green background, "Get weather" label with search icon. Hover: #246b44. Loading: spinner replaces icon, label changes to "Looking up…", button disabled.

**Error state:**
- Inline banner below input row, red background (#FEF2F2), red text, alert circle icon
- Input border turns red with red focus ring
- Message: "That doesn't look like a valid eBird checklist ID."

**Output area (appears after successful lookup):**
- Revealed below a horizontal divider within the same card
- Eyebrow label: "WEATHER OUTPUT" in 11px / weight 600 / uppercase / muted gray
- Copy button: right-aligned, 30px tall, light green background, primary green text and icon. On copy: turns solid green with checkmark icon and "Copied!" label for 2 seconds, then reverts.
- Output block: monospace font, 13.5px, 1.75 line-height, light gray background (#F4F4F5), 1px border, 8px radius, 18px/20px padding

**Footer (below card):**
- "SnowRaven · self-hosted weather for birders" in 12px / #b0b0b8

## Component Usage
- Text input: custom styled, not a shadcn component — keeps the layout tight
- Primary button: custom styled with brand tokens
- Copy button: custom styled with accent background and primary color
- Error banner: inline div with flex layout
- Output pre block: `<pre>` with monospace font stack

## Design Tokens Applied
- `--primary: #2D8653` — submit button background, input focus ring, logo accent, copy button text
- `--primary-hover: #246b44` — submit button hover state
- `--accent-bg: #E8F5EE` — copy button resting background
- `--muted-bg: #F4F4F5` — output block background
- `--muted-fg: #71717A` — tagline, eyebrow label, footer text
- `--border: #E4E4E7` — input border, card border, output block border
- `--fg: #0F1117` — all primary text
- `--radius: 8px` — inputs, buttons, output block

## Interaction Notes
- Enter key submits the form (same as clicking the button)
- Loading state: search icon swaps to spinning loader, button disabled, label reads "Looking up…"
- Copy success: button icon swaps from clipboard to checkmark, background goes solid green, reverts after 2 seconds
- Output section is hidden on load; slides into view after first successful lookup (no page reload)
- Input validation happens client-side before any API call: must begin with "S" followed by digits (after URL stripping)

## Content Notes
- All copy is plain and direct — no marketing language
- Error messages tell the user what to do, not what went wrong internally
- Attribution line in the output: `Weather generated by <a href="https://github.com/dtgibson/snowraven">SnowRaven</a>`
- The output block displays raw HTML in the attribution line — this is intentional, as eBird renders HTML in checklist comment fields
