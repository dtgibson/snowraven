# Implementation Notes — Checklists Tab (Stage 5, The Engineer)

## PR description

### Checklists Tab (v0.5.27)

#### What this does
Adds a new top-level **Checklists** tab: a checklist-comment search box, an
all-species species-comment search box, and a filterable expandable list of all
checklists — under a tab-wide "Show weather & tide blocks" toggle (default
hidden) that strips pasted SnowRaven/Raincrow weather and NOAA tide blocks from
both display and search ("search matches what you see"; an empty-after-strip
comment counts as no comment, PRD FR-05/06/07).

#### How to test
1. `cd backend && uvicorn main:app --reload --port 1620`
2. `cd frontend && npm run dev` → http://localhost:5173
3. Open the new **Checklists** tab (after Named Birds). With an eBird backup
   saved in Settings, all three sections populate; without one, the setup gate
   shows.
4. Search "Humidity" in Checklist Comments → 0 matches; flip the toggle → your
   weather-blocked checklists match.
5. Compose filters (e.g. Breeding codes → has, Media → doesn't have) and watch
   the "N of M checklists" count.

#### Notes for reviewer
- New pure module `lib/checklistsTab.ts` (+27 tests) and
  `stripWeatherTideBlocks()` in `lib/commentBlocks.ts` (fixtures generated by
  the REAL weather/tide formatters so format drift breaks tests). Stripping is
  SPAN-based (emoji header → end of attribution link), never line-based —
  eBird's export collapses pasted newlines so prose shares the block's line
  and can follow the attribution. Includes fallbacks for moon-emoji night
  blocks (RainCrow), attribution-less blocks, and emoji-less condition
  segments — all shapes found in real data and pinned by regression tests
  (see decisions.md, Stage 5 entries). Verified against the user's full
  backup: 308 block-bearing comments, 0 residue leaks.
- The comparer's file-local `CommentText` is lifted to shared
  `components/CommentText.tsx` (no behavior change).
- Strip runs on entity-DECODED text; entries pass already-decoded text back
  through `commentSegments` (decode is ~idempotent; only double-encoded
  entities like `&amp;amp;` would differ — accepted).
- Tab registry: `parseLayout` auto-appends `checklists` (visible) to saved
  layouts — locked by a new test. HELP TOC also gains the previously-missing
  Named Birds entry; the comparer's `### Checklists` heading became
  `### Checklists mode` to avoid an anchor-id collision with the new section.
- Checklist `speciesCount` counts ALL taxa (incl. spuh/slash), matching the
  eBird checklist page (Statistics' spuh toggle intentionally not replicated).
- `formatDuration()` takes HOURS; the CSV stores MINUTES — the row passes
  `duration / 60` (the known gotcha, see codebase-research).

## Seeing the Checklists tab locally

1. Open a terminal in your project folder.
2. Start the backend: `cd backend && uvicorn main:app --reload --port 1620`
3. In a second terminal: `cd frontend && npm run dev`
4. Open http://localhost:5173 and click the **Checklists** tab (between Named
   Birds and List Comparer).
5. You should see: the Checklist Comments box (10 most recent, searchable),
   the Species Comments box (all species), and the All Checklists list with
   filter pills. Weather/tide blocks are hidden until you flip
   **Show weather & tide blocks**.

## Convention Flags
- **Cycling tri-state filter pill** (one pill: off → has → doesn't-have, label
  restates its condition) as the pattern when a tab has too many filter
  categories for paired Has/No pills. First used here; logged in
  pipeline/checklists-tab/decisions.md.
- **`components/CommentText.tsx` is now THE shared safe comment renderer** —
  new code should import it rather than re-implementing entity-decode +
  linkify + line breaks.
- **`stripWeatherTideBlocks()` lives beside the detectors in
  `lib/commentBlocks.ts`** and must stay marker-synced with
  weatherFormatter/tideFormatter (tests enforce via real-formatter fixtures).
