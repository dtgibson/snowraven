# Change Brief — Code Search and A11y Polish

**Improve lane, design pass needed (item 2 only).** Three small existing-surface fixes in one run. Target: the next patch version (1.0.56 unless a parallel ship has taken it), six-file bump plus `CHANGELOG.md` at deploy.

## What is changing
1. **Media Targets search uses the shared species matcher.** On Map Explorer's Media Targets view with no ML export, the **Target Species** search box (`filteredManualSpecies`, `MapExplorer.tsx` ~line 949) is a plain lowercase substring over common names. It moves onto `normalizeSpeciesQuery` + `rankSpeciesMatches(rows, q, alphaCodeHits(...), matchesSpeciesQuery)` from `lib/speciesMatch.ts`, the same call `SpeciesCombobox` makes. So a typed code (`yrwa`) finds the bird, code matches lead and the rest keep the list's own order (rule A, no `order` argument), and scientific names match too, exactly like every other picker. Rows should be the existing `speciesOptions` memo (`{name, sciName}`), so the code index built for the My Sightings picker is shared rather than rebuilt. The 60-row cap applies after ranking. The box starts the lazy code load when it is focused (a third `loadAlphaCodes()` trigger) and never waits for it; rows look exactly as before.
2. **Named Birds card fits at 320px and 200% text.** Three known overflows, all clipped by the card today: the "Media of {name}" header does not wrap a long spaceless name (up to 1,595px), the gallery tiles' `nowrap` "Macaulay Library" link (and the checklist link beside it) runs up to 36px past a three-column tile at 641px / 200%, and each sighting row's checklist link runs about 110px past the card's content box at 320px / 200%. That last row is `date · location · checklist` on one line, with date and link both `flexShrink: 0`, so the location probably collapses to nothing as well (not yet measured). The card is fixed and measured as one unit.
3. **Tier-3 milestone badge hover and focus contrast, light mode.** The shared `.sr-birdname-link:hover, :focus-visible` rule paints `--sr-accent` (#277448) on light tier 3's darker stop (#C6E2D5) at 4.14:1. Tiers 1, 2 and 4 measure 5.09, 4.66 and 5.13:1 (re-computed for this brief). The fix is a badge-scoped hover/focus color (a fifth badge-local property beside the four `data-tier` already sets) that changes only light tier 3, plus light-mode rows in `milestoneContrast.test.ts`, which goes red on today's value.

## Why now
The user asked for all three together. Each was pre-existing, measured and parked with its fix named: item 1 is ROADMAP's species-code follow-on (1), which the 1.0.55 brief scoped out of that release (FR-21); item 2 is the Named Birds overflow ROADMAP item and saved idea, measured by ml-media-links' QA at 1.0.54 and frozen there by its FR-10; item 3 is the saved idea and ROADMAP item from 1.0.50, whose reversal condition was "the user takes the idea".

## User-facing impact
- Media Targets (no ML export): typing a four-letter code or a scientific name now finds the bird in the Target Species list, with code matches first. Nothing else about the list changes.
- Named Birds: at phone widths and large text, a long name wraps in the media header, tile links stay inside their tiles, and each sighting row's date, place and checklist link stay inside the card. Desktop at 100% text should look unchanged.
- Statistics: in light mode the species name on a tier-3 milestone badge turns a slightly darker green on hover and keyboard focus. Every resting color, dark mode and the other tiers are unchanged.

## Design pass
**Needed for item 2, the Named Birds card at phone width and large text.** The sighting row needs a real layout choice: what gives way when date, place and checklist link cannot share a line (wrap the link beneath, stack the place on its own line below 640px, or something else), without losing the place name or the link. The tile meta row needs one too: let "Macaulay Library" wrap, move the links to their own line, or fewer columns at large text. Show the card in both themes at 320px / 200%, 641px / 200% and desktop at 100%, with a long spaceless name and a typical one. What should feel better: nothing clipped or hidden, the row still reads date first, the link still easy to tap.
**Not needed for item 1:** rows, copy and layout are unchanged; only which rows match, and their order, change.
**Not needed for item 3, or for item 2's header:** each is mechanical. The header wraps its text with `overflow-wrap: anywhere` on a `min-width: 0` span. For tier 3, the Engineer picks the darkest change that holds: the same hue as `--sr-accent`, darkened only until it clears 4.5:1 on both stops with margin (about #236A41 gives 4.75:1), every other tier keeping `--sr-accent` exactly. The Designer may show it as one swatch in the same mockup; it needs no exploration.
