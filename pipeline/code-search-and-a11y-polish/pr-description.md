## Code search and accessibility polish (code-search-and-a11y-polish)

### What this does
Three small fixes to existing surfaces. On Map Explorer's Media Targets view without a Macaulay Library export, the **Target Species** search now uses the same species matcher as every picker: a four-letter code (`yrwa`) finds the bird and leads the list, and a scientific name matches too. The Named Birds card now fits at phone widths and large text: the long-name headers wrap, each sighting row keeps its place name and puts the checklist link on its own line when it cannot share one, the gallery drops to two columns then one as the section narrows, and the header's date range breaks instead of being clipped. In light mode, the species name on a tier-3 milestone badge (500 to 999) turns a darker green on hover and focus, so it clears AA.

### How to test
1. Map Explorer, Media Targets, with no ML export loaded: type `yrwa` in the Target Species box. Yellow-rumped Warbler (and any of its forms in the backup) lists first. Type `calypte`: Anna's Hummingbird. Type `warbler`: the same rows in the same order as before.
2. Named Birds: open a card for a bird with a long name and media. Narrow the window to a phone width, or set Settings, Text size to the largest. Nothing is cut off at the card's or a tile's edge; each sighting row shows its place; the checklist link sits on its own line under the date when the row is narrow. At a desktop width and default text size the card looks as it did.
3. Statistics, light theme: hover or Tab to the species name on a 500, 600 or later milestone badge. The name turns a slightly darker green than on the 100 to 400 badges. Dark mode is unchanged.
