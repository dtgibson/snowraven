The ramp and its states

A new cyan-blue token family, --sr-hotspot-1..5, declared identically in both themes because it only ever paints on the always-light basemap. Luminance falls monotonically (every step at least 1.33:1 from its neighbor, every fill at least 3:1 against the palest land tint), so the scale reads in grayscale with no texture needed at pin size. Whatever is not a number never borrows the ramp: it gets structure instead of hue.

Grayscale proof, and the structural cues

In grayscale the five classes still order themselves. The three off-ramp states never rely on their gray: not checked yet wears a dashed ring, zero and quiet are hollow, and never birded is a pale, empty pin, the same "unrecorded means unfilled" idea the county overlay already taught. The visited check and unvisited dots ride every pin, so "an active hotspot I have never visited" stays a readable combination.

Recent activity, working honestly

Mode 3 asks eBird one bounded question per hotspot and caches the answer for six hours. Everything that can go wrong has its own words, keeps whatever already arrived, and offers a retry that never re-runs the hotspot search.

The popup, state by state

Every pin's number, or the honest reason there is none, in words. The shipped popup content stays; the mode line joins it. The "Hotspots in view" list carries the same reading, so nothing here depends on perceiving color.

Decisions taken in this direction

React to any of these. Changing them now is fast and free.

  • DecidedZero and quiet share one fill.
    "Asked, and the answer is zero" is one visual idea: the hollow pin. They never appear in the same mode, and the popup words differ ("only spuh and slash entries" versus "no reports in this window"). Confirming the Architect's shared token.
  • DecidedNever-birded is a pale, empty pin, not a dark gray.
    No data must read as absence, and any dark fill inevitably reads as "something." The dark ring carries its visibility, the shipped teardrop practice. This deviates from one clause of the planned contrast guard (the pale fill is under 3:1 against land by design, with the ring supplying the boundary), logged in decisions.md for the Engineer's guard to encode.
  • DecidedColorblind path: luminance plus structure, no per-tier texture.
    A county-style density hatch does not resolve on a 28px teardrop. The ramp is strictly luminance-monotonic (grayscale-ordered), the off-ramp states are structural (dashed, hollow, pale), the kind glyph rides every pin, and the popup and in-view list state every value in words.
  • DecidedActivating a mode reveals the legend.
    The legend is the scale's explanation; a new coloring with a closed legend is a riddle. Kind filters stay one press away as glyph chips, since color no longer encodes kind while a mode is active.
  • NoteMode 3 counts eBird's taxa as returned.
    The Architect flagged this: recent-activity counts mirror eBird's own tallies with no countable-form collapse, so the popup label says "species reported," matching what eBird would show for the same window.
  • NotePhone tier.
    The mode grid and window pills join the sidebar's filter block under .sr-ctl-row, every pill at the 16px floor and 44px touch posture at 640px and below, wrapping two-up. The mock presents desktop; the spec carries the phone rules.
