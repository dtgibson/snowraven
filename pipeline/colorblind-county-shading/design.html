Use Textures — a color-free read of the county ramp

An optional mode that encodes each county's count tier as crosshatch density instead of hue, so the choropleth ranks the same way for colorblind and low-vision birders. It mirrors the atlas overlay's existing Use Textures toggle and stays off by default.

Legend treatment

How the sidebar legend reads with textures on (OQ-01): density swatches in tier order, the active-metric label intact, the toggle above. The "Counties in view" disclosure carries the same swatch at 11px next to each numeric value.

Why replace, not show both. With textures on, the user has opted into the color-free read. Keeping color swatches as well re-introduces the cue the mode exists to remove and crowds a ten-row legend. Density leads; the green tint still carries through faintly so the switch isn't jarring.

Light and dark. The map fills and the swatches use the same green in both themes — the county ramp is basemap-anchored, since the Positron base stays light under both app themes. So density, not theme, does the work; only the surrounding app chrome flips. Use the toggle up top to confirm.

A starting point, not the final word. The two knobs are line spacing and line weight; spacing carries tiers 1–6 and weight takes over at 7–10 so the top tiers stay separable without going solid. React to anything — the tier-1 floor, how dense tier 10 should get, whether the top three pull apart enough.
