Desktop App Phase 2 — OS Keychain

Infrastructure reference for the Tauri API key storage migration. No UI changes.

Write Path

Settings UI → storage.setApiKey('ebird', key) → TauriStorage updated

→ invoke('set_api_key', {service, value}) primary (OS Keychain)
→ POST /settings/keys/ebird bridge (best-effort)

Read Path

storage.getApiKey('ebird') → invoke('get_api_key', {service}) → OS Keychain → key or null

Rust Commands (lib.rs)

#[tauri::command]
fn get_api_key(service: &str) -> Result<Option<String>, String>

#[tauri::command]
fn set_api_key(service: &str, value: &str) -> Result<(), String>

#[tauri::command]
fn delete_api_key(service: &str) -> Result<(), String>

Keychain Entry Layout

Service:  "SnowRaven"
Account:  "ebird"       | "openweather"
Value:    [key string]

macOS    → Keychain Access → generic password
Windows  → Credential Manager → generic credential
Linux    → Secret Service (libsecret)
