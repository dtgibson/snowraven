Designer notes for this review

  • What you are looking at. The shipped iCloud Sync section grown by one switch, "Sync API keys", directly under the file switch, off by default. Its helper line matches the file description's shape; while it cannot be operated it carries its one-line reason ("Turn on iCloud Sync first.", or the same availability note the file switch shows). The status row and Check now cover both passes. The Remove row now holds two controls, each naming only what it removes.
  • The note before turn-on (state 3) is the focal moment. Six leads in the app's plain voice: what goes to iCloud, whose account, how Apple protects it, which devices, what happens next, how to stop, and one closing line promising nothing is written until Turn on. The protection item says exactly what iCloud provides: encrypted in transit and at rest by Apple, end-to-end only with Advanced Data Protection.
  • Provenance and state on the key rows reuse the Default Files sync line unchanged: a small glyph, the state label as text, then "From this device, changed <time>" or "From iPad, changed <time>". Replaced and Cleared lines take the place of the provenance while set; Retry sits on the same line. Each line is the same polite status region as the file rows.
  • The state strip flips through every state in the contract. The live controls also work: both switches, the Turn on path (Syncing to Up to date), Show and Hide, Check now, Retry, Clear with key sync on (its confirmation names the reach), both Remove controls and their confirmations.
  • Widths. Mac (980), 641px (the desktop tier at its narrowest), and 320px (the phone tier: rows stack, buttons take the 44px posture). State 16 carries a 64-character device label with no spaces, the longest line any state can produce; try it at 320px and 200% text.
  • Nothing new in the palette or type. Every color is a shipped token in both themes; every size is a register the tab already uses. Windows and web builds render none of this.
