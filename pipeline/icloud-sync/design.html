Designer notes for this review

  • What you are looking at. The Default Files rows as they are today, plus a new iCloud Sync section directly below them. Nothing above or below moves. The section is in the tab's quiet register: the uppercase header names it (and is the switch's accessible name), the card holds one explanatory line beside a bare switch, a status row, and a Remove row that appears only when iCloud holds something.
  • Sync state on the rows. One muted line under "Saved": a small glyph, the state label as text, then provenance ("From this device" / "From Dave's Mac (Mac)") and, where a different file is involved, its upload time. Download now and Retry sit on that same line as quiet buttons. Each line is a polite status region, so a state change is announced once.
  • The state strip above the frame flips through every state in the contract. The live controls also work: the switch opens the enable note, Turn on walks through "Syncing, uploading" to "Up to date", Check now checks, Download now and Retry download, Clear (sync on) and Remove open their confirmations.
  • Dialogs scale in from the control that opened them (ease-out, under 200ms), trap focus, close on Escape or the backdrop, and return focus to that control. Reduced motion renders everything near-instantly.
  • Phone tiers. iPhone (390) and 320px use the iOS "Import" wording. Rows stack, every button takes the 44px touch posture, and 320px at 200% text scale has no horizontal scroll. In the build these hang off the shipped ≤640 / ≤480 tiers.
  • Copy. The enable note carries the four required elements in the app's plain voice; the eight state labels and the three availability notes are the contract's exact words.
