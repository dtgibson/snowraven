Appearance

First design direction

The nearest bird you need, on the home screen

A Nearby Lifers widget set to the week, and a Media Targets widget set to today, beside the apps a birder already keeps. Switch Appearance above to see light, dark and the tinted home screen; turn on Larger text to see rows drop rather than clip.

Bay Area, a late September morning. Every name is a real species a birder there could chase; every distance is measured from the phone.

iPad a large Nearby Lifers over 30 days and a medium Media Targets for the week, same extension

What holds the two widgets together with the app: the raven mark in the header, the exact view names from Map Explorer, and one accent color spent on one thing, the distance. Everything else is ink and gray, so the list reads as a list and the number reads as the answer.

Every size

One bird, three birds, eight birds

Small is a single-bird card: the name big, the distance bigger. Medium and large are the same row repeated, nearest first, with the update time in the footer. The window sits in the header as a word, never a control, because a widget cannot hold one. On Media Targets set to Any, a small camera, microphone or video glyph beside the name says what the bird still needs.

A new report lands nearer than the rest; rows settle in 200 ms, the only motion WidgetKit allows.

States

One sentence, and the title never leaves

Each state says which one thing is missing, in the register of the Map Explorer overlays. A stale list is still a list, marked by words in the footer, never by color. Nothing is ever blank.

The state set and its precedence come from the plan; this is the copy as it would ship. Medium shown for all; the last tile shows how small carries a stale mark.

Configuration

Time range, and for Media Targets, Media

Long-press, Edit Widget. The sheet is iOS's own; we supply the parameters and their values. Day, Week and 30 days are the same three words as the in-app Time Range control. Media Targets adds Media: Photo, Audio, Video or Any, with Any the default. Nearby Lifers has Time range only.

Any means missing any of the three, which is exactly what Map Explorer's Media Targets lists under its All chip.

Edit Widget Week and Any are the defaults for a newly placed widget

Time range a change re-lists from the cache, no new eBird request

Media four values, each with a second line saying what it means

Tap-through

Tap the bird, land on that bird

Tapping a bird opens Map Explorer on the matching view with the widget's window (and media setting) applied and a 25 mile search run from the phone, then shows only that species, centered on the sighting the widget listed with its details open. One pill in the map's bottom-right cluster brings every nearby bird back. Tapping the widget anywhere else (the header, empty space, a state message) lands on the view with all nearby birds, as before.

The "Only ... · Show all" pill is the cluster's existing action row, in the accent-tinted register the Search this area button already wears. On a phone it sits above the round buttons; on a desktop window it sits in the same corner of the map, beside the sidebar, and the sidebar's count reads "1 spot · 1 lifer".

The edge in frame 4: the app searches when it lands, and the tapped bird may not be in the new results (the report aged out of the window, or the phone moved). Then every nearby bird is shown and the map's statement line says why, in the register the search-outcome line already uses. Never an empty map. The details popup, the selected chip, the pill register and the statement line are the shipped Map Explorer's own.

VoiceOver

Read in full, with the unit spoken

The widget is one element to VoiceOver: title and window, then each row as one sentence with the location name (even on small, where it is not drawn), then the update time and any caption. "mi" on screen is "miles" in speech.

Media Targets under Any the glyphs are spoken as what the bird needs

Text uses the system text styles, so it follows Dynamic Type. At larger sizes the medium widget shows two rows and the large five, each row whole; a long name truncates on screen while its spoken label stays complete.
