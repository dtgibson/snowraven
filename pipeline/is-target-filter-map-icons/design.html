Is Target Filter & Map Icons

Three UI moments: a new filter pill in the Media List, per-species missing-type icons on target map pins, and a cross-tab navigation link on the target count.

"Is Target" uses an amber/orange tone to distinguish it from the positive green pills ("Has media," "Has photo") and the negative red pills ("No photo"). It's a targeting concept, not just a positive/negative filter. Clicking "All" resets it.

Icons show only what's missing — never what the user already has. Camera = no photo, mic = no audio, video camera = no video. Icons are 10px SVGs using stroke="currentColor", inheriting the pill's text color. Appears to the right of the name on the same line.
