Start it whenever you need it:
cd /opt/snowraven && ./start.sh
Then open http://localhost:1620 in your browser.
API keys and data files are configured in the Settings tab.

Script is curl-pipe safe — all logic runs inside main(), so a partial download never executes halfway.

Existing .env is never overwritten — re-running on an existing install updates the build and leaves your keys intact.

Works on Pi OS Bookworm/Bullseye and Ubuntu 22.04 / 24.04. Node installed via NodeSource if not already present.
