## Findings

### F-1 — Popup built from an HTML string (Informational)
**Where:** `AtlasBlockLayer.tsx` `onEachFeature` → `layer.bindPopup(htmlString)`
**Description:** The block popup is assembled as an HTML template string interpolating the block `name` and `code`. If those values were ever attacker-controlled, this would be an injection vector. They are **not**: both come from the bundled `ca-atlas-blocks.json`, which is generated by our own offline converter from the official atlas KML — trusted static data, no user input flows in. `code` is additionally `encodeURIComponent`-wrapped in the href. Risk is effectively nil as built.
**Remediation:** None required. If the block source ever becomes dynamic/user-supplied, switch to DOM construction or escape the interpolated values.
**Status:** Accepted (trusted static data)
