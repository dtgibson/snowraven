## Map Explorer before Calendar

### What this does
Swaps two entries in `DEFAULT_TAB_ORDER` (`frontend/src/lib/tabLayout.ts`) so the Map Explorer takes the Calendar's slot and the Calendar takes the Map Explorer's. The default now reads Weather, Statistics, Map Explorer, Species Detail, Calendar, Multimedia, Breeding Codes, Checklists, List Comparer, Named Birds. Because the phone bar is the first four visible tabs in the saved order, its default four become Weather, Statistics, Map Explorer, Species Detail, and the More sheet opens with Calendar.

One normalizer step rides with it so the new default reaches devices that already have a layout on disk (the tab layout is device-local and never synced): `parseLayout` now compares the saved order, after its existing unknown-id drop and missing-tab append, against the 1.0.18 default kept as `PREVIOUS_DEFAULT_TAB_ORDER`; an exact match reads as the new default with its hidden set intact, and any other order is returned as saved. Nothing is written back on load (hydration never persisted, and still does not); a migrated layout is persisted only when the user next reorders, hides, shows or restores. Settings' Restore defaults compares against `DEFAULT_TAB_ORDER`, so a migrated layout reads as default there too.

The version is stamped 1.0.19 (first app-affecting build of this Spool bundle) and eight of the eleven website screenshots that show the navigation are recaptured.

### How to test
1. `cd frontend && npx vitest run src/lib/tabLayout.test.ts src/components/TabNav.test.tsx` (70 tests) and `npx vitest run src/lib/icloudKeysPublishedClaims.test.ts` (the version-parity guard, 37 tests). Both green here; `npm run typecheck`, `npm run lint` and `npm run build` all exit 0.
2. Start the app (`cd backend && .venv/bin/uvicorn main:app --reload --port 1620` and `cd frontend && npm run dev`, then `http://localhost:5173`) with no saved tab layout. The sidebar reads Weather, Statistics, Map Explorer, Species Detail, Calendar, then the rest. Narrow the window to 640px or under: the bar reads Weather, Statistics, Map Explorer, Species Detail, More; More opens with Calendar at the top.
3. Migration by hand: in Settings, drag the tabs into the old order (Weather, Statistics, Calendar, Species Detail, Map Explorer, Multimedia, Breeding Codes, Checklists, List Comparer, Named Birds), optionally hide one or two, and reload or relaunch. The order comes back as the new default with the hidden tabs still hidden, and Restore defaults reads as already at the default. Swap any other pair instead (for example Breeding Codes and Checklists), reload, and that order is kept verbatim.
4. On web you can also set `localStorage['sr-tab-layout']` to `{"order":[<the old default>],"hidden":["comparer"]}`, reload, and confirm the stored string is byte-for-byte unchanged after the load.
