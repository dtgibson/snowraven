Button states Overview

The "Use my location" button already exists in the Hotspots and Media Targets sidebars. This feature upgrades its behavior — adding a loading state, platform-specific error messages, and proper Tauri plugin support so it actually works in the desktop app.

Default State 1

Button shows the crosshair/locate icon and "Use my location" label. Hover reveals a green border and light green background — consistent with the existing accent treatment. Lat/lng inputs below are empty, ready to be filled.

Acquiring position State 2

Spinner replaces the icon; label changes to "Locating…"; button shifts to muted background and is disabled. The lat/lng inputs remain visible but unchanged. Spinner animation runs until the position resolves or times out (10 second limit).

Location found State 3

Button briefly shows a check mark and "Location found" in green. Coordinate inputs fill with the resolved values and gain a green border + light background to signal they were just populated. If the fields were previously empty, the active mode's fetch fires automatically.

Error State 4

Error message appears between the button and the lat/lng inputs. On macOS Tauri, the message directs the user to System Settings. On the web (Pi), it says "Allow location access in your browser settings." A "Position unavailable" or timeout error shows a simpler fallback message.

Tauri path: tauri-plugin-geolocation → requestPermissions() → getCurrentPosition()

Web path: navigator.geolocation.getCurrentPosition() — already works in browsers, unblocked by the existing HTTPS/isSecureContext check removal

What changes in the code Engineering notes

1. Tauri dependency
Add tauri-plugin-geolocation to Cargo.toml, register in capabilities, add NSLocationWhenInUseUsageDescription to bundle config.

2. New utility: location.ts
Platform-branching getCurrentLocation() function — returns { lat, lng } or throws a typed error. Called from MapExplorer, testable in isolation.

3. handleUseMyLocation upgrade
Add isLocating state. Call getCurrentLocation(). On success, set lat/lng and trigger fetch if fields were empty. On error, set typed error message.

4. Remove isSecureContext check
The current guard blocks the button in Tauri (where isSecureContext is false). The Tauri path doesn't need this check — the plugin handles permissions natively.
