Named Birds gets the compact list: one numbered link per item of the bird, grouped by format and numbered newest first, each opening that item's Macaulay Library page, the same page as the tile's own link. It covers every item, including the ones behind "Show more", and needs nothing from the export's filename.

Species Detail is unchanged. Its Media card already links each format's count to the same catalog view a Recent Media row would have opened, so that row was dropped as redundant. Hover or Tab to any number to see what a screen reader hears and where it goes.
