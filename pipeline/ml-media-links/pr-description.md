## Macaulay Library links in a named bird's media section (ml-media-links)

### What this does

Each named bird's "Media of {name}" section on the Named Birds tab now opens with a compact list of numbered links, one per media item of that bird, grouped Photos, Audio, Video and numbered newest first within each format. Each number opens that item's own Macaulay Library page, the same URL as its gallery tile's "Macaulay Library" link. The list covers every item, including those behind **Show more**, and is identical whether the embedded players are working, blocked by Cornell's bot check, turned off in Settings, or offline. That matters because the bot check currently blocks every player.

### How to test

1. Build the frontend (`cd frontend && npm run build`) and serve it (`cd backend && .venv/bin/uvicorn main:app --port 1621`), with an eBird backup and a Macaulay Library export saved in Settings.
2. Open **Named Birds** and expand a bird that has media.
3. Under "Media of {name}", check the lead line "{name} on Macaulay Library, newest first:" and one row per format the bird has, in the order Photos, Audio, Video.
4. Hover a number: its box fills and the tooltip shows the item's date. Click one: that item's Macaulay Library page opens in a new tab (the system browser in the desktop and Apple apps).
5. Tab through the list: each number is a tab stop, Photos first, then Audio, then Video, then the gallery's controls. The focus ring sits 1px off the box with no halo.
6. Compare a number with the tile it belongs to (reveal all with **Show more**): the URLs match. The list is the same before and after **Show more**.
7. Turn on **Disable embedded media** in Settings and come back: the list is unchanged and still sits above "Embedded media is disabled in Settings."
8. Narrow the window to a phone width (640px or less): each format label moves above its numbers and the numbers become 44px tap targets with no gap between them.

### Notes for reviewer

- **Structure follows schema.md.** The grouping is a pure function, `mediaItemLinkGroups`, in `lib/mediaEmbed.ts` (beside `MEDIA_CATALOG_ID_RE`, which it reuses as the tile's own gate). The list is a module-private `NamedBirdMediaLinks` component in `NamedBirdMedia.tsx`, next to the tile, so the list's `mlAssetUrl(item.catalogId)` sits beside the tile's identical call. No new source file. D3's suggested separate `NamedBirdMediaLinks.tsx` was not needed.
- **Rule gating.** `frontend/src/components/NamedBirdMedia*.tsx` is added to `.claude/rules/security.md`'s `paths`, because the file renders hrefs (CLAUDE.md, the paths obligation). It was already inside `media-embeds.md` and `ui.md`. No other rule file changes.
- **The list reads only `assets` and `birdName`.** The derivation is `useMemo(() => mediaItemLinkGroups(assets), [assets])` above the early return, and the list is the first child of the `total > 0` fragment, so it holds one slot in every embed state and is neither moved nor remounted by an embed change. It reads no embed preference, bot-check gate, online status, reveal count, storage, transport, contributor id or taxon code.
- **Security.** The only value from the file that reaches a URL is the catalog id, gated by `MEDIA_CATALOG_ID_RE` and encoded by `mlAssetUrl`, both the tile's own. The bird's name reaches only text and an `aria-label`. The only DOM ids are `useId()` plus the format index. The format lookup is a `Map` over the three known formats. Declared scan: one linear pass over the open bird's gallery per ML load. Per listed item, one anchored digits-only test and one constant-time `formatDate` at render.
- **No network change.** No third-party request, no new endpoint or host, and no request moved between components, on any target. The links go to `macaulaylibrary.org/asset/<id>`, which the tiles already link to. `tauri.conf.json`, `capabilities/default.json` and `PRIVACY_POLICY.md` are untouched.
- **Accessible names** follow D3: "Photo 3 of 24 of Winky, Jan 18, 2026, on Macaulay Library (opens in a new tab)". The date and its commas drop out when an item has none. Each format group is a `role="list"` named by its visible label.
- **Styling** uses existing tokens only. Base rules sit beside the media section's rules in `globals.css`. Phone rules go inside the established 640px tier. The one deliberate deviation is the local focus-ring override (`outline-offset: 1px; box-shadow: none`), per D3. That rule sits BELOW the global focus ring, beside `.sr-segbar-btn:focus-visible`, because it ties the global `[tabindex]:focus-visible` on specificity and wins only on source order. QA attempt 1 caught it placed beside the base rules, where it lost and the focused number kept the 3px offset and the halo. The built CSS differs from HEAD by exactly the 15 intended rules, with nothing removed and no utility emitted from test files.
- **Help.** Two sentences were added to the Named Birds "Media of a named bird" paragraph in `docs/HELP.md`, guarded by `namedBirdMediaLinksHelpClaims.test.ts`. No `website/` copy, `README.md`, App Store or privacy-policy text changed.
- **Pre-existing, outside scope (FR-10 keeps it unchanged).** The section's own header, "Media of {name}", does not wrap a long spaceless name. With the 120-character name the harness uses, it overflows the card by up to 1,595px, and the card clips it. Separately, the tiles' `nowrap` "Macaulay Library" and checklist links pass a three-column tile by up to 36px at 641px / 200%. Both measure identically with the list hidden. The harness checks that the list adds none of it, and prints the rest as allowed.
- **Tests:** `lib/mediaEmbed.test.ts` (4 rows, fixtures through the production join), `components/NamedBirdMediaLinks.test.tsx` (22 rows: every QA row a component can reach, including a Tauri runtime click through `test/tauriOpener.ts`), `lib/namedBirdMediaLinksHelpClaims.test.ts` (5 rows), and the real-engine harness `website/tools/verify/verify-named-bird-media-links.mjs`. The harness covers QA-25 / QA-26 over 96 layout configurations per engine. It also checks the focus ring after a real Tab, in light and dark themes at 1024px and 390px. Its `--expect-broken` leg must turn the reflow, target and focus checks all red; the focus leg deletes the list's focus rule through the CSSOM. `NamedBirdMedia.test.tsx` is unmodified and green.
