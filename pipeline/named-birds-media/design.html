Named Birds — media section

A media block under a named individual's sightings map: that bird's own Macaulay Library photos, audio, and video, each anchored to its capture date and checklist. Designed to look native to the Named Birds tab and stay light — a tidy grid of labeled tiles, not a wall of live players.

Both themes shown side by side. Token values are copied verbatim from globals.css. One tile embeds a real Macaulay Library player to show true scale; every other tile is a correctly-sized styled placeholder (which doubles as the real loading/offline state).

1 · In context — below the map, within the expanded row

The section sits directly under the "Where {name} has been seen" map block, using the identical uppercase micro-label + lucide icon the map header uses. Header: Media of {name} · a quiet "Showing 6 of 11" on the right.

Every state keeps the same tile footprint so switching between them never shifts the layout, and every state keeps the date + checklist link (they're local, always known). The offline/failed tile adds a "View on Macaulay Library" link-out so the item is never useless.

Mockup notes · The one live embed (top-left of Section 1, light pane) shows the true Macaulay player scale; all other tiles are styled placeholders that also serve as the real loading / offline states. Placeholder heights match the live player exactly, so the grid never shifts when a real embed mounts. Format hues reuse existing token families — photo = accent green, audio = --sr-is-target amber, video = --sr-tier-3 purple — introducing no new brand color. All text meets WCAG AA in both themes.
