SnowRaven · nav-rework · design pass

Eleven destinations, one navigation,
three densities.

The horizontal strip needs about 1,409 px and swaps for a single scrolling dropdown the moment it would overflow — so an unmaximised laptop window, an iPad and every phone all get the dropdown. This replaces it with a vertical sidebar, an icon rail and a phone bottom bar, chosen from measured available width. Drag the width slider and watch the density change; switch Nav to Today at any width to see what ships now.

What each density is doing

Sidebar — the brand comes with it

The wordmark, glyph and tagline move out of the page header and into the top of the nav column, so the content column starts at the top of the window. That is roughly 150 px of vertical chrome returned to every tab, on every wide window.

Grouping: one line, and only one

No named groups. The user reorders freely, so any category label becomes a lie the first time they do. The one honest separator sits above Settings, whose position is structurally fixed — it is appended after the saved order and is never part of it.

Settings is not pinned to the bottom

It sits directly under the list behind its hairline, exactly as the shipped dropdown already draws it. Pinned to the floor it would read as a different kind of thing, and it would float alone whenever the user hides most tabs.

Collapse narrows, never widens

The toggle can step an affordable sidebar down to the rail. It can never force a sidebar the measurement says will not fit, so it cannot contradict the derivation — and it is session-only, so nothing new is stored and no relaunch can restore a density that is wrong for the window.

Rail: three ways to know where you are going

The icon, a tooltip on hover and keyboard focus, and an aria-label that is always present. Where you are is answered by the page header the tab already draws — which is the touch answer on iPad portrait, where there is no hover.

One proposed icon change

Multimedia uses lucide List today, which is indistinguishable from Checklists’ ClipboardList at rail size. Images is proposed instead. Toggle it in the bar above to compare. Approved: Multimedia ships with Images.
