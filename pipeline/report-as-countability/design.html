Report-As Countability

Design refinement, Stage 2. Four control labels and the notes behind them. Nothing visual changes.

One noun, two verbs. The excluded set is no longer nameable as three kinds of thing, so the labels stop trying. They use the word the code and the help text already use, forms, with Count where the control moves a number and Show where it moves rows. This joins the sentence v0.5.87 already ships and which is still correct under the new rule: "Counts leave out forms that don't count toward a life list, including escapees."

5 · Why no explanatory panel

Re-derived independently against the bundled snapshot rather than taken from the brief. The v0.5.87 escapee panel was built for a number that only ever fell, resolved over the network in about ten seconds, and needed seven status states. This rule is offline, instant, deterministic, and mostly moves the number up.

6 · The one rule, as the help text will state it

SnowRaven follows eBird's own rule for what counts as a species. A form that leaves the species in doubt does not count (a spuh, a slash, a hybrid, an undescribed form). A form that only leaves the subspecies in doubt counts as its parent species.
  • One rule, stated once. It matches what the code now does and explains both directions of the delta without a table.
  • It retires the intergrade-named-inside-a-trailing-parenthetical explanation that appears in four separate help passages, because eBird's data now answers what that mechanism was inferring.
  • Eleven docs/HELP.md passages change in the same edit, along with the matching claims in README.md and website/index.html.
