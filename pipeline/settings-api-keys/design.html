Design notes
1 API Keys sits above Default Files — it's the more critical first-run configuration. Both sections use the identical header pattern (uppercase label + horizontal rule).
2 Lock icon replaces the file icon for key rows. Green when set, grey when not — same colour logic as the file rows' FileCheck/FileQuestion icons.
3 The input field expands inline below the row header (not in a modal or separate page). Save is disabled until the user types something. Cancel collapses the input without saving.
4 Show/Hide is a text toggle next to the masked value — not a button with border. Keeps the action lightweight; it's a display preference, not a data operation.
5 The footnote under the API Keys card explains the immediate-effect behaviour without requiring the user to know what .env means.
