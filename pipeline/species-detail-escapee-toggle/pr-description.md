## Species Detail Escapee Toggle (1.0.18)

### What this does
Species Detail gains a third toolbar switch, **Show escapees**, off by default, after Show subspecies and Show all forms. With it off, a species that eBird tags Exotic: Escapee on every checklist the user recorded it on is left out of the species selector and the "N species" figure, so that figure reads the same as the Statistics Species headline at both tabs' defaults; one press restores the rows and the number. The tab reads the escapee set passively through the shipped `useProvenanceLookup` hook (the Calendar and Map Explorer pattern): no request, no key, and each published name is confirmed against the persisted checklist ledger using this tab's own observations. The confirmed design-gate deviation ships with it: the boxed `ToggleSwitch` gets an app-wide hover state (border to `--sr-border-medium`, fill to `--sr-surface-subtle`, 120ms ease-out).

### How to test
1. On a device where Statistics has already run the exotic-status check and found escapees (the reference export finds Graylag Goose, Swan Goose and Muscovy Duck), open Species Detail. The toolbar shows three switches; the count reads the Statistics Species figure (264 on the reference export, where it read 267 before).
2. Open the selector: the escapee species are absent. Turn Show escapees on: the count rises by the number of escapees and the species are back. Turn it off again: they go.
3. With Show escapees on, pick Muscovy Duck, then turn the switch off: the selection clears. Pick a non-escapee and repeat: the selection stays.
4. Turn Show subspecies on with Show escapees off: `Muscovy Duck (Domestic type)` is hidden with its parent. Turn Show escapees on: both rows appear.
5. On Statistics, expand the escapee list and click a name: Species Detail opens with Show escapees turned on and that species selected. Open the Subspecies and forms control on Species Detail with the switch off and pick Muscovy Duck: same reveal.
6. On a device where Statistics has never run the check, the switch is present and pressing it changes nothing; every count and option matches 1.0.17.
7. Hover any framed switch (Species Detail, Multimedia, the Counties switch on Statistics, the Checklists weather switch): the border and fill step to the hover tones in both themes. The Counties switch while its data is loading, and any disabled switch, stay at rest.
8. `cd frontend && npx vitest run src/components/SpeciesDetailEscapees.test.tsx src/components/ui/ToggleSwitch.test.tsx src/lib/exoticProvenanceGraph.test.ts` and `npm run build`.

A hybrid clicked on Multimedia with that tab's Show all forms on used to open Species Detail with nothing selected; it now reveals. The Subspecies and forms control (`pickExplorerSpecies`) goes through the same helper, because it lists every species with a form noted, which includes an escapee carrying a domestic-type form; before this it could select a name the selector was hiding. Not named in the brief; a consequence of the display-list layer, handled in the same one-condition shape.
- Open questions 2 to 5 and 7 took their defaults: deselect on switch-off mirrors `handleToggleSpuh`; the layer is on `displaySpeciesList` and `countableKeys` is untouched; the hook input is `phase.tag === 'ready' ? phase.observations : EMPTY_OBSERVATIONS` with a module constant; the switch always renders; the component test mocks `../lib/exoticProvenanceCache` at `getSnapshot`/`loadSnapshot`/`subscribe` and drives the real hook and real `confirmExcludedNames`. The hover rule is gated `:not(:disabled):not([aria-disabled="true"])` so an inert switch (not-allowed cursor) never lights up as operable. Reduced motion is handled by the global `*, *::before, *::after` block in `globals.css`, which the standing note there says is the ONLY mechanism (no per-component query); the rule's comment says so.
