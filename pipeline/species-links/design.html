Icons appear after the comparison taxonomy fetch resolves — fired immediately after Compare Lists is clicked. The comparison result is shown instantly; icons appear a moment later as codes arrive. Resetting the comparison clears the taxon map, so old icons never bleed into a new comparison.

Component Spec

SpeciesLinks — renders when speciesCode is truthy, returns null otherwise.

Wrapper: display:inline-flex; align-items:center; gap:5px; margin-left:6px; vertical-align:middle
Icons: 14×14px img inside a[target=_blank][rel=noreferrer]
Error handling: onError → img.style.display='none'
Hover: icon opacity 0.75 → 1.0

eBird link: https://ebird.org/species/{speciesCode}
BOW link: https://birdsoftheworld.org/bow/species/{speciesCode}/cur/introduction
eBird favicon: https://ebird.org/favicon.ico
BOW favicon: https://birdsoftheworld.org/favicon.ico
