## Layout Decisions

### Life List Accumulation
- Granularity toggle sits flush-right above the chart, aligned with a "Life list accumulation" sub-label on the left
- Toggle order (left to right): Total · Yearly · Monthly · Weekly — Total is active by default
- In Total mode the chart renders a step line (horizontal then vertical segments), not a smooth area curve
- In period modes the chart renders the existing smooth area curve (unchanged)
- First/Last observation cards appear as a horizontal row of cards (`obs-card` style) above the chart
- Each card shows: small muted label, large bold date (accent-colored link when valid submissionId), and a muted location line with a pin icon
- Milestone pills: each pill shows the milestone count (large accent number), species name (bold), and linked date below it; all in `sr-accent-bg` with `sr-accent-border`

### Firsts & Milestones
- Biggest single day: the species count is the clickable element (accent color, external-link icon), with date + location as muted sub-text below

### Temporal Stats
- For Protocol, Month, and DOW sections: bars on the left, donut pie on the right, using `.chart-pair` grid (`1fr 148px`)
- Pie charts are 100×100 SVG donuts; generated by JavaScript using correct arc math (see `makePie()` in design.html)
- Protocol pie: 4 distinct colors matching the bar colors (green / blue / purple / amber)
- Month pie: sequential green scale (lightest for low-count months, darkest for May); center text shows "peak / May"
- DOW pie: 3 grouped slices — Sat (dark blue `#1D4ED8`), Sun (medium blue `#3B82F6`), Weekdays (light blue `#93C5FD`); center text shows "wkend / 43%"; legend uses solid dot colors (no opacity hack)
- "By start hour" section has no pie — bar chart only, same as current
- Pie legend items: colored dot (8px circle) + label text at 10px muted, stacked vertically

### Geographic Stats
- County bar rows: the label is an `<a>` link styled in `sr-text` color (not accent), so it reads as a plain label with hover underline
- Footnote below the county list: "County names link to their state/province eBird region page" (11px muted)

### Effort & Methodology
- Protocol distribution: horizontal fill bars, 28px tall, with the protocol name + percentage shown above each bar in a flex row
- Small bars (< ~10%) show the count value outside the bar to the right, in muted text
- Key metrics grid: 4 equal cells, `surface-subtle` background, 22px bold value, 10px uppercase muted label
  - Cells: Avg Duration (min) / Avg Distance (mi) / Spp / Hour / Spp / mi
  - Distance values converted from km (× 0.621371) before display
- Average-by-protocol table: left-aligned Protocol column, right-aligned numeric columns; `—` for missing data
- Observer chart: vertical bar chart, 110px tall, bars are full-width accent color; count label inside bar top if bar is tall enough; observer label below each column

### Data Quality
- Count method bar: two-segment proportional bar, 32px tall; green segment for numeric, slate for X/presence
- Comment coverage bar: same style; blue for with-notes, light slate for no-notes; "no notes" segment uses dark text (not white) because the background is light
- Biggest-counts table: Species left-aligned, Count right-aligned in accent color (linked), Date right-aligned (linked, muted), Location right-aligned (muted, no link)

### Fun Stats
- One-and-done pills: `pill-link` style — surface-subtle background, border, accent text; hover shifts to accent-bg
- Nemesis methodology: left-bordered callout box (`border-left: 3px solid sr-accent-border`), italic, 12px muted text, sits above the nemesis list

## Color Usage

All colors use `var(--sr-*)` tokens. Chart colors use the existing CSS variables:
- `--sr-accent` (#2D8653) — primary/Traveling/numeric-count segment
- `--chart-blue` (#3B82F6) — Stationary/DOW bars/comment-coverage segment
- `--chart-purple` (#8B5CF6) — Area protocol
- `--chart-amber` (#F59E0B) — Incidental protocol
- `--chart-slate` (#94A3B8) — presence-only (X) segment

No hardcoded hex values in component JSX. Any new tokens needed must be added to both `:root` and `[data-theme="dark"]` in `globals.css`.

---

## Link Behavior

All eBird outbound links: `target="_blank" rel="noreferrer"`, no visible URL, external-link icon (11×11 SVG) inline after the linked text where the link is the primary value (dates, species counts). Pills and county labels do not show the icon.

Validation gates (enforced before rendering any `<a>`):
- Checklist links: submissionId must match `/^S\d+$/`
- Region links: stateProvince must be non-empty and contain at least one hyphen

---

## Interactive Behavior

- Granularity toggle: clicking a button calls `switchGran(mode, btn)` — removes `.active` from all buttons, adds it to the clicked one, shows/hides `#chart-total` vs `#chart-period`
- Total mode chart: step path built from `liferPoints` array (one point per lifer, sorted by date); area fill uses gradient
- All other interactivity is unchanged from current implementation

## Recharts Components Used

| Section | Chart type | Components |
|---|---|---|
| Accumulation (Total) | Step area | `AreaChart`, `Area` (type="stepAfter"), `XAxis`, `YAxis` |
| Temporal pies | Donut | `PieChart`, `Pie`, `Cell` (no `Legend` — custom legend below) |
| Effort protocol | Horizontal bar | existing inline div bars (no Recharts) |
| Effort observers | Vertical bar | `BarChart`, `Bar`, `XAxis`, `YAxis` |
| Data quality props | Proportional bar | inline div bars (no Recharts) |

---

## Accessibility Notes

- All `<a>` elements have meaningful text content (date, species count, county name) — no icon-only links
- External-link icons have `aria-hidden="true"` or are purely decorative
- "—" cells in tables are plain text, not empty cells
