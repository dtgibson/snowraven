Rest, hover, keyboard focus, and a personal place

Hover underlines the name in its own color over 120ms (instant under Reduce Motion); keyboard focus takes the app's global 3px accent ring. The glyph follows the last word of the name on the same line, like a trailing character, so a wrapped name reads as one link rather than a block with an arrow off to the side; it never drops onto a line by itself.

Other surfaces

The same link everywhere a full hotspot name shows

The fix lives in the shared link, so every tab that shows a full hotspot name gets it: Species detail, Named Birds, the Weather backlog, a Birding Statistics card, the county popup. One row from Species detail's recent sightings, 300px wide, as shipped and as amended. Truncated and icon-only links are untouched.

Decided

Wrap, green link, and the glyph beside the last word

Approved on the mockup: long hotspot names wrap (eBird puts the part that tells two hotspots apart at the end of the name, and truncating cuts exactly that part); the green link at this size and weight is right; personal places stay exactly as today.

Amended after the live look at the built app: "It would look much better and flow more logically if the link button was right next to the link, instead of off to the side." Fixed in the shared link rather than only on Targets.

What changes
  • Only the Last report place. The date above it, the ticks, the distance and the sort order are untouched.
  • A personal place looks exactly as today. Same muted gray, same size, same line, same wrap.
  • Hotspot green, one line per row, 0.75rem. The same weight and glyph as a hotspot in Checklists and Named Birds, so a long list stays calm: nothing is bolder or larger than the date it sits under.
  • The spoken name is the app's shared one: "Open Lake Merritt on eBird (opens in a new tab)".
  • Both themes, AA. Light accent #277448 is 5.71:1 on white and 5.47:1 on the row-hover surface; dark accent #34D399 is 9.22:1 on the card.
  • No new tokens, no new component. One change inside the shared hotspot link (the glyph rides with the last word), three short rules on the existing .sr-tg-place line and one phone-tier rule.
