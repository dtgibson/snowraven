# Design Spec — Targets Tab

**Feature:** targets-tab
**Date:** 2026-09-26
**Stage:** 4 — The Designer (approved after review round 1; amended 2026-09-27 on re-entry after the live look: section 2a, the measuring-point chooser, FR-51a / QA-53a)
**Mockup:** `pipeline/targets-tab/design.html` (the approved rendering; this document describes it, the mockup is the visual reference)
**Design system:** `pipeline/design-system.md` applies in full. No new tokens. One new control pattern, the distance slider (see Component Usage and the flag at the end).

## Visual Direction

Quiet utility, exactly the register of the shipped tabs: house header, one controls card, a quiet "eBird bar chart" section, and the list in a card. The one design problem the tab exists to solve, keeping **probability** (eBird's historical percent-of-checklists frequency from the county's bar-chart file) and **live** (what the eBird API reports now) unmistakably apart, is solved four ways at once and never by color:

1. **Two labelled kinds.** On desktop the list is a table whose columns are grouped under two headers, **PROBABILITY** (lucide `Percent` glyph, source line "eBird bar chart, Alameda, CA, 1900-2026") and **LIVE** (lucide `Radio` glyph, source line "eBird API, last 30 days"), separated by a hairline. On a phone every row carries the same two labelled blocks inline.
2. **Two shapes of figure.** A probability is a percent with its sign under a short continuous share bar (a proportion). A live figure is a sentence with a count and its window, "Reported 12 of the last 30 days", under a strip of thirty discrete day ticks (a count). Bars and ticks are `aria-hidden` reinforcement; the text carries the meaning.
3. **Words in every header, sort name and cell.** Every probability header and sort option carries "%" and names its source and range; every live cell names its window and never contains a percent (FR-36, FR-42, FR-58). The same words are in the accessible names.
4. **Restraint.** Both kinds are monochrome (`--sr-text`, `--sr-text-muted`, `--sr-border`). The accent goes only where the app always puts it: active controls, the species link, and the one primary action per state (Add file when the county has no file).

The tab sits after Calendar in the navigation, with lucide `Target` as its icon (fallbacks per schema §6.2).

### 2a. Where distances are measured from (2026-09-27 re-entry amendment, FR-51a / QA-53a, user-approved)

The measuring point for the Distance cells, the Distance sort and the distance slider is chosen in the tab, from the status line, without a map.

**Trigger.** The anchor's name inside the status line is a `Button` (`.anchor-btn`: inherits the line's type at 600 weight in `--sr-text`, a 1px dashed `--sr-border-medium` underline, an 11px ChevronDown glyph in `--sr-text-muted`; hover lifts text and underline to `--sr-accent` / `--sr-accent-border-strong`). In the no-anchor state the trigger is the call to action "Choose where to measure from" in `--sr-accent` with no underline. Attributes: `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls` = the dialog id. Accessible name: "Distances are measured from {anchor name}. Change" (anchor names: "your Default Location", "your location", "Livermore", "Arrowhead Marsh"), or "Choose where distances are measured from" when nothing is set. Absent entirely when there is no live data.

**Dialog** (`role="dialog"`, `aria-label="Measure distances from"`; `--sr-surface`, 1px `--sr-border`, radius 10, `--sr-card-shadow`, padding 6, 22rem wide and never wider than its row, anchored below the trigger at the row's left edge; full row width on the phone tier). Contents in this order, each heading in the section-label register (0.6875rem/700 uppercase `--sr-text-muted`, the later ones over a `--sr-border-subtle` rule):
1. Heading "Measure distances from".
2. **My location** (LocateFixed glyph): sub-line "Finds where you are now". Activating it calls the existing location seam (`getCurrentLocation`, no new permission storage); while locating the item reads "Finding your location"; a failure shows `describeLocationError` text in the `--sr-error` line under the item and leaves the previous anchor in force.
3. **Default Location** (MapPin glyph): sub-line "Oakland, set in Settings"; when no Default Location is saved the item is native `disabled` with the sub-line "Not set in Settings".
4. Heading "A place", then the app's existing place search (Map Explorer's `AddressSearch`: a 34px text input `aria-label="Search by place name"`, placeholder "Search by place name", 1.5px `--sr-border-input`, `--sr-accent-border-strong` on focus; beside it a 34px Search icon button, `aria-label="Search"`, `--sr-accent` fill with `--sr-on-accent`, disabled on `--sr-surface-subtle` while the field is empty). **Submit-only**: Enter or the button sends ONE Nominatim forward-geocode request through the existing `/nominatim/search` route and its queue, never a request per keystroke. Under the field the hint "A town, park or address, looked up on OpenStreetMap when you press Search." (0.6875rem `--sr-text-muted`); on a miss the hint is replaced by the app's exact line "No location found. Try a different search term." in `--sr-error` (`role="alert"`, sequence-keyed child); offline reads the seam's offline line. A hit becomes the anchor, named by the query as the user typed it (trimmed), the dialog closes.
5. Heading "Places in this list", then one item per distinct last-report place among the rows currently on screen, **alphabetical** (`localeCompare`), MapPin glyph, the place name, and at the right its distance from the CURRENT anchor in 0.71875rem `--sr-text-muted` tabular ("6.0 mi"), omitted when there is no current anchor. The list scrolls inside 11.5rem. With no live data the section does not exist (the dialog is unavailable); during a partial sweep the section holds the places found so far and grows as days land; a county with no last reports yet shows the heading and the line "No reports in the last 30 days yet" in `--sr-text-muted` italic. The section is built from the sweep's own day records (place name and coordinates), so it costs no request and works offline from the cache.

Items are `Button`s (`.apop-item`: 34px min, radius 6, `--sr-text`, hover `--sr-surface-subtle` at 120ms ease-out); the anchor in force carries `aria-current="true"` and the `--sr-accent-bg` / `--sr-accent` treatment; a disabled item takes `--sr-text-disabled` and `cursor: not-allowed`.

**Focus and closing.** Opening moves focus to the first enabled item. Escape, choosing an item, a successful search, and a click outside all close through one path and return focus to the trigger; a search miss keeps the dialog open with focus in the field. Tab stays inside while open (the shared `useFocusTrap`, `containOutsideFocus: false`, the ModalDialog posture). While open the trigger reads `aria-expanded="true"`.

**Effect of a choice.** Every Distance cell, the Distance sort and the slider re-measure from the new anchor at once (`distanceMiles` from the anchor to the same last report the cell shows); the slider keeps its stop and its `aria-label` becomes "Distance from {anchor name} to the last report" ("Distance from the measuring point to the last report" with no anchor); the distance sort's disabled reason with no anchor reads ", choose where to measure from"; the empty state reads "... within 5 miles of Arrowhead Marsh." (the anchor name in place of "your Default Location").

**Scope: session-only (user decision).** The chosen anchor is React state in the tab: it survives a county change within the session (it is a coordinate; only the "Places in this list" section follows the county), it is never written through the `storage` seam (a device position must never be persisted and a searched place would be a new document), and a relaunch measures from the Default Location again, or shows the no-anchor state when none is saved. The county stays the tab's one remembered choice (FR-08).

**Phone tier.** The dialog takes the full width of the status row (`width: 100%`) and sits below the line; its items are 34px and the search field 34px with the 16px floor; verified at 360px at 100% and 200% text in both themes with no horizontal overflow.

**Not done, and why.** No map: maplibre and the county geometry stay off this tab, and a "tap a point" map would cost the lazy map chunk plus a location-input map for one control. Not a hotspot fetch: the county's hotspot list would be a new request kind; the sweep's own places cover the real question at no cost.

## Component Usage

- `Button` / `Link` primitives for every control (the `tabIndex={0}` default), including the sort buttons inside `<th>`, the county chevron, the link-styled Use my location / Show unmatched / Open bar chart controls and the species-name button.
- `SpeciesCombobox`-shaped county picker (schema §6.3: its own `aria-activedescendant` listbox, index-keyed ids, not the species component itself).
- `.sr-pill` for the three type toggles; Map Explorer's media-chip register for Photo / Audio / Video; `.sr-segbar` for Last report (and its compact `--seg` variant for the breeding threshold); `.sr-btn-quiet` (+ `--danger`) for Replace / Remove; `.sr-btn-accent` for Add file; `.sr-th-sort` for the header sort buttons; the grid-collapse disclosure for the unmatched list; `TabLoadErrorAlert` for the load-error phase; the standard setup-required panel for no backup (FR-09).
- `<BirdName>` for every species name; `openExternalUrl` for the ebird.org link; `SyncLine`-shaped always-mounted status regions.
- **Measuring-point chooser (2026-09-27):** the status-line trigger `Button` plus a small `role="dialog"` built from existing parts: the shared `useFocusTrap`, Map Explorer's `AddressSearch` (extracted to a shared component so the two cannot drift, submit-only, same "No location found. Try a different search term." line and offline line), the location seam for My location, and plain `Button` items for the Default Location and the list places. Glyphs: LocateFixed, MapPin, Search, ChevronDown. No new tokens.
- **New: the distance slider.** A native `<input type="range" min="0" max="5" step="1">` over the stop ladder [Any, 1, 5, 10, 25, 50] with `aria-label="Distance from your location to the last report"`, `aria-valuemin/max/now` and `aria-valuetext` = the phrase ("Any distance", "Within 1 mile", "Within 5 miles" …), `aria-describedby` = the status line. Drawn from the ToggleSwitch's tokens: 4px track in `--sr-border` with the span up to the thumb in `--sr-accent`; an 18px thumb in `--sr-switch-thumb` with `--sr-switch-thumb-shadow` and a 1.5px `--sr-accent` ring; the global focus ring. Stop labels (0.625rem `--sr-text-muted`, tabular) sit under the thumb centres at `9px + (100% - 18px) * i/5`, except that the first label is pinned to the track's start and the last to its end so neither overhangs the track (amended 2026-09-27, user-approved); the current stop in `--sr-accent` 700; the last reads "50 mi", and on a narrow track (the stops row's container query at 20.3em: 320px from 125% text, 360/390px from 150%) it reads "50" so it cannot collide with "25", while the value phrase still says "Within 50 miles". Disabled: native `disabled`, track and thumb in `--sr-border` / `--sr-gray-400` / `--sr-surface-subtle`, labels and value in `--sr-text-disabled`, and the value snaps to "Any distance" (a disabled slider never shows a narrowing it is not applying). 16rem wide on desktop, full width on the phone tier. This is the app's first slider (Map Explorer's Radius is a SegControl); the pattern is recorded in decisions.md and should be folded into `pipeline/design-system.md`.

## Design Tokens Applied

- Text: `--sr-text` for figures, names, kind labels and the summary count; `--sr-text-muted` for labels, headers, status lines, the "Reported" lead, units and the "%" sign; `--sr-text-gray` for scientific names; `--sr-text-disabled` for disabled controls only.
- Borders: `--sr-border` cards, pills, share and tick tracks, group rules; `--sr-border-subtle` row separators; `--sr-border-medium` LIFER badge, the badge's inner rule, unchecked-tick outline; `--sr-border-input` the county field and the sort select.
- Accent: `--sr-accent` (+ `--sr-accent-bg`, `--sr-accent-border`, `--sr-accent-border-strong`) for pressed pills and segbar options, the active sort caret, the species link hover, link-buttons, the selected county option, the slider's filled span, ring and current stop label, the focus ring; `--sr-on-accent` on the Add file button; `--sr-accent-strong` its hover.
- Media chips: `--sr-is-target-bg` / `--sr-is-target-border` / `--sr-is-target-text`.
- States: `--sr-error` / `--sr-error-bg` / `--sr-error-border` for Remove and the refusal alert; `--sr-warning` for the cooldown clause.
- Slider: `--sr-switch-thumb`, `--sr-switch-thumb-shadow`, `--sr-gray-400`.
- Depth: `--sr-card-shadow` on the cards and the listbox; `--sr-sticky-shadow` on the pinned column-header row.

All sizes in rem so the in-app Text Size scales them; the tick strip and the share bar are px and deliberately do not scale.

## Interaction Notes

- Default sort: this-month when the county's file covers the current month, else the live sort, else Taxonomic (FR-49); a user-chosen sort persists across county changes while available. Sorting is instant, never animated.
- The window and the distance slider are live-data filters: with no live data both are disabled and hide nothing; the slider is also disabled with no anchor. A row is hidden by the window only when its last report is outside it or every day in the window is checked and none reported it; by the slider only when its last report is known and farther than the stop, or every day in the window is checked and none reported it (FR-53, FR-54a). Both never hide an unchecked row during a partial sweep.
- The measuring point is chosen from the status-line trigger (section 2a): My location, Default Location, a searched place (submit-only Nominatim) or a place from the list; the choice re-measures the distance cells, the distance sort and the slider in place; the status line always names the anchor in force; the choice is session-only and survives a county change. (Amended 2026-09-27; this replaces the earlier Use my location / Use Default Location link pair.)
- Pool, badges and the alphabetical / taxonomic sorts render before any network call; every control keeps working during the pool fetch and the sweep (FR-12, FR-59). Rows fill in progressively as days land.
- Add / Replace / Remove re-evaluate the default sort; a refused import leaves everything as it was and reports the reason in the alert region.
- Keyboard: Tab reaches every control; the county listbox is `aria-activedescendant`-driven (ArrowDown/Up, Enter commits, Escape closes only the open list); the slider steps one stop per arrow key; pills and segbar options are one tab stop each with `aria-pressed`; the measuring-point dialog takes focus on open, traps Tab, and Escape / a choice / a click outside return focus to its trigger.
- Accessible names carrying the kind: the probability sort options and header buttons contain "%" and "eBird, {County}, {y1}-{y2}, {September | year-round}"; the live cells read "Reported N of the last 30 days" / "... of K days checked so far" / "Not reported in the last 30 days"; the slider's `aria-valuetext` is the "Within N miles" phrase and its `aria-label` names the anchor ("Distance from Arrowhead Marsh to the last report"); the chooser trigger reads "Distances are measured from {anchor}. Change"; the summary live region reads "27 targets: 14 lifers, 9 media, 8 breeding".
- DOM ids are index-keyed (`tg-county-opt-{i}`, `tg-row-{i}`), never built from a species or county name.

## Motion Spec

- County listbox open: `cubic-bezier(0.2, 0, 0, 1)`, 140ms, transform-origin top center, scaleY 0.92 + fade; reduced motion instant; close instant. CSS.
- Measuring-point dialog open: the same 140ms `cubic-bezier(0.2, 0, 0, 1)` scale-and-fade, transform-origin top LEFT (it hangs from the trigger's left edge); reduced motion instant; close instant; item hover 120ms ease-out background. CSS.
- Pill / chip / segbar / slider ring / nav item colour change: ease-out, 120ms, no transform; reduced motion instant. CSS.
- Unmatched-names disclosure: `grid-template-rows` 0fr to 1fr, `cubic-bezier(0.2, 0, 0, 1)`, 180ms; reduced motion instant (transition still ends, so `inert` release keeps working). CSS.
- Sweep progress bar width: `cubic-bezier(0.2, 0, 0, 1)`, 220ms; reduced motion instant. CSS.
- A day tick landing: background-color / opacity, ease-out, 160ms, no transform; reduced motion instant. CSS.
- Nothing else animates: sorting, filtering and figure changes are instant, no row entrances, no hover scale. Reduced motion is the app's global block in `globals.css`, never a per-component query.

## Content Notes

- Voice: short, specific, never promotional; every unavailable figure says why in the PRD's exact words; no em dashes anywhere (ranges are "1900-2026", "Jan-Dec").
- The county is always "{Name}, {ST}" ("Alameda, CA"); distances are "5.6 mi"; dates are "Sep 24", "Today", "Yesterday"; counts are "1,183 checklists"; percents are two decimals with the sign.
- Probability copy always names eBird, the county and the file's range; live copy always names the window and the count; neither borrows the other's noun.
- Anchor copy (2026-09-27): the status line always says "Distances from {anchor}" plus one short clause naming the kind ("(Oakland)", ", found just now", ", a place you searched", ", a place in this list"); a searched place is named exactly as the user typed it, trimmed; list places carry eBird's location name unchanged.
- Every copy string above is single-sourced in `lib/targets/targetsCopy.ts` for the copy guard (schema §9.2).
