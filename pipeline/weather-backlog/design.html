Weather Backlog

A new section at the bottom of the Weather tab — “List checklists with no weather blocks.” Designed entirely within SnowRaven’s existing system: real --sr-* tokens (light + dark), the Weather-tab card, and the Checklists-tab row anatomy. Toggle the theme and the phone view to see it hold.

1Collapsed entry point

Sits as a third block at the bottom of the Weather tab, below the single-checklist lookup and the Current/Predict panel (both shown faintly for context — unchanged by this feature). One click expands the list in place; it never navigates away. The 30px accent icon tile echoes the app’s house-header pattern.

2Expanded backlog & row anatomy

The header states the count and active filter context, then the widen toggle (default OFF). Each row mirrors the Checklists-tab row: date · location · badges, with the species count right-aligned in accent green. A second line carries protocol, completeness, and effort. The three actions live on their own row — two neutral icon buttons (open checklist ↗, open comment/edit page) and one accent Copy weather & go. Rows below show the mid-lookup, success, and failure states.

4Per-row failure states — the edit page is never opened on failure

Action #3 does the weather lookup first. If it fails, the failure is reported inline on that row, in the app’s honest three-state vocabulary (reusing the shared OfflineMessage treatment) — and the comment/edit page is not opened, so the user never lands on eBird with nothing on their clipboard. Each row’s state is independent.
