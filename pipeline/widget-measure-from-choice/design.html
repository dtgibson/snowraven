Appearance

Starting point, surface 1

One more row in a sheet that already exists

Long-press, Edit Widget. The sheet is iOS's own; we supply the rows. The new row is Measure from, the exact words Alerts uses in Settings and the Targets tab uses in its chooser. Its two values are My location and Default Location, the Targets chooser's own pair, because the second value is the Default Location, so its name says so where Alerts' "Fixed place" could not. My location is the default and is today's behavior to the letter, so a widget placed before the update changes nothing.

Nearby Lifers gets it as its second row, Media Targets as its third, after the rows a birder already knows. Tap a value in the third phone, or use the Measure from control above: every proposal on this page follows it.

Surface 2

The caption says where the distances come from, however it got there

Today "From your default location" appears only as a fallback, when the phone could not be located. The proposal shows it whenever the list was measured from the Default Location, chosen or fallback, with the same words. The reason is the mixed home screen: a Nearby Lifers from home beside a Nearby Lifers from here look identical without it, and the caption is the only place the tile can say which is which. It is true in both cases, and it is one string rather than two.

A Default Location in Fremont, Alameda County, for a birder reading the widget from the office in San Jose. Same reports, different distances, because the reference point moved.

Surface 3

Default Location chosen, none saved

A new state with its own sentence, in the register every widget sentence uses: name the one thing in the way and the two ways out, as the existing no-location sentence does. It makes no request. The two ways out are the two things the birder can actually do from there: save a Default Location in the app, or put the widget back on My location.

Today's sentence stays for My location with neither a position nor a Default Location. The new one is only ever shown on a widget set to Default Location.

TodayNo location, no Default Location My location, unchanged

"Open SnowRaven to allow location, or set a Default Location in Settings." Still shipped, still the My location sentence.

ProposedDefault Location chosen, none saved

"Set a Default Location in SnowRaven's Settings, or switch this widget to My location." Names the value as the picker spells it, so the way back is findable.

Surface 4

The gallery no longer promises "where you are"

The widget gallery's description is the only place the widget explains itself before it is placed, and today it says "within 25 miles of where you are". With a choice, that is true of one value. The proposal names both in the same breath and changes nothing else in the sentence. The Shortcuts-facing intent descriptions gain the same clause.

The description lives in the gallery, under the name; the Edit Widget sheet shows only the rows.

Surface 5

A tap lands where the list was measured from

Tapping a bird on a widget whose list came from the Default Location opens Map Explorer searched from the Default Location, with no location read, so the bird the widget listed is on the map. The landing line reuses the alert link's wording and drops "near you": Finding Ruff… rather than Finding Ruff near you…, because the search point is not where the phone is. A tap on the widget outside a bird still says "Finding nearby lifers…", which is true from either point.

On the map, the difference is the center: the pin where the search was run from sits on the Default Location, and there is no blue dot for the phone, because nothing asked where it was.

The tap carries which point the list came from, chosen or fallback, so the map matches the widget in both cases. A widget on My location that did locate the phone taps through exactly as today. The "Only Ruff · Show all" pill, the popup and the statement line are the shipped Map Explorer's own and do not change.
